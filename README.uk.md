# 🍰 The Sweet Workshop

Адаптивний лендинг для **The Sweet Workshop** — бренду хендмейд десертів,
орієнтованого на красиву подачу, якісні інгредієнти та зручний процес
замовлення.

## 📖 Про проєкт

**The Sweet Workshop** — це лендинг, створений для демонстрації колекції
крафтових десертів та представлення концепції й цінностей бренду.

Вебсайт містить каталог десертів, детальну інформацію про кожен десерт, відгуки
клієнтів, FAQ та процес замовлення.

## Фічі

- Адаптивний дизайн
- Динамічний каталог десертів
- Модальне вікно з деталями про десерт
- Рейтинги десертів
- Слайдер відгуків клієнтів
- FAQ
- Модальне вікно замовлення
- Toast-сповіщення
- Індикатори завантаження
- Адаптивна навігація з бургер-меню
- Інтеграція з Backend API

## 🛠 Технології

### Фронт-енд

- HTML5/CSS3
- JavaScript
- Інтеграція з API

### Бібліотеки

- **Axios** — API-запити
- **Swiper.js** — слайдер відгуків
- **Toastify.js** — toast-сповіщення
- **ldrs** — індикатори завантаження
- **css-star-rating** — рейтинги у вигляді зірок

### Інструменти

- **Vite**
- **Git / GitHub**
- **VS Code**
- **Figma**

## Концепція Проєкту

Головна мета проєкту — створити привабливу та апетитну онлайн-присутність для
бренду хендмейд десертів.

Дизайн зосереджений на:

- представленні асортименту десертів;
- створенні привабливої та надійної атмосфери;
- підкресленні якості та унікальності кожного десерту;
- забезпеченні простого та зручного процесу замовлення.

## Яку проблему він вирішує?

Вебсайт надає клієнтам зручний спосіб знайти домашні десерти в одному місці без
необхідності зв'язуватися з кондитерською безпосередньо, щоб дізнатися про
доступні продукти.

Він допомагає бренду презентувати свої продукти, надавати детальну інформацію
про десерти, збирати відгуки клієнтів та робить процес замовлення простим і
доступним з будь-якого пристрою.

## 🚀 Щоб почати

Клонуйте репозиторій та встановіть залежності:

```bash
git clone <repository-url>
cd the-sweet-workshop
npm install
```

Запустіть сервер розробки:

```bash
npm run dev
```
